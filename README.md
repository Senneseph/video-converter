# Multi-Platform Video Converter
A free, self-hosted conversion service for YouTube, Instagram, X, Facebook, TikTok.

## Launch

1. Create a .env file.
2. Specify PORT, defaults to 1337
3. Run `docker-compose up -d`
4. Open a browser to `http://localhost:1337/` or `http://localhost:[PORT]/`
